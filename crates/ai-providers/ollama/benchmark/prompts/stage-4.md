Create a Vite React project with TypeScript directly in the current directory. Start with execute_command using program `mise` and arguments `["exec", "--", "npx", "--yes", "create-vite@latest", ".", "--template", "react-ts", "--no-interactive"]`. Then install dependencies using program `mise` and arguments `["exec", "--", "npm", "install"]`. Build with program `mise` and arguments `["exec", "--", "npm", "run", "build"]`. Inspect every failure and continue working in the same agent loop until the build succeeds. Do not stop before the build succeeds unless the system prompt's five-attempt tool-unavailability exception applies.
